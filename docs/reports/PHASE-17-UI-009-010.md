## 4. Invariants & Security Architecture Verified

1. **Zero Client Trust (RULE-SEC-002):**
   - Frontend calculates live preview totals for UX feedback, but the backend `CreateOrderRequest` and `OrderService` authoritatively re-evaluate line item totals, tax calculations, pricing floor constraints, and inventory reservations.
2. **Pricing Boundaries (RULE-PRI-002):**
   - Product order card displays minimum price floors and MRP ceilings. Normal orders strictly enforce `minimum_allowed_price <= actual_order_price <= mrp`.
3. **Territory Resource Scoping (RULE-SEC-003):**
   - Salesman A can only access Territory North customers; Salesman B can only access Territory South customers. Cross-territory order creation is blocked server-side (HTTP 403).
4. **Non-Destructive Order History (RULE-DOM-001):**
   - Baseline line item quantities are preserved across adjustments and delivery dispatches.
5. **Non-Production Data Safety:**
   - `ManualTestingSeeder` strictly verifies application environment before inserting synthetic data.
